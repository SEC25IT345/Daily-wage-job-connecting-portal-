# Daily-wage-job-connecting-portal-

The Daily Wage Job Connecting Portal is a web-based platform that connects daily-wage workers with local employers and small businesses. It helps workers find suitable jobs based on their skills and location.

Features

- Worker registration
- Job posting for employers
- Search jobs by skill, category, and location
- English-to-Tamil language support
- Simple and user-friendly interface
- Responsive design for mobile and desktop

Technologies Used

- HTML
- CSS
- JavaScript

Target Users

- Daily-wage workers
- Local employers and contractors
- Small businesses
- Farmers and households

Project Objective

To make local job opportunities more accessible and help workers connect with employers easily.

How to Run

1. Download or clone this repository.
2. Open "index.html" in a web browser.
3. Explore the job search, registration, and job posting features.

Future Enhancements

- Database integration
- Secure worker and employer login
- Location-based job matching
- Tamil voice assistance
- Job notifications and application tracking

Project Status

Student prototype — demonstration version. Registration and job-posting data are not permanently stored.
